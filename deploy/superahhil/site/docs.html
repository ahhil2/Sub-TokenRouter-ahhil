中转站是什么？

SuperAHHilAi 是面向 AI 工具和开发者的 API 中转网关。你可以使用同一个账户、同一套余额和统一的 API Key，连接 OpenAI 兼容、Anthropic 兼容、Gemini 原生等不同类型的模型入口。

统一入口

一个控制台管理余额、令牌、日志和模型可用性。

多协议兼容

支持 OpenAI、Claude、Gemini 等常见工具链。

按需接入

按工具选择正确 Base URL 与分组即可开始使用。

常用 Base URL

Claude / Anthropic: https://superahhilai.top
OpenAI / Codex:     https://superahhilai.top/v1
Gemini native:      https://superahhilai.top

注册账号

1. 打开注册页

访问 superahhilai.top/register，进入注册界面。

2. 填写资料

输入用户名、邮箱、密码和邮箱验证码。请使用可接收邮件的邮箱。

3. 完成创建

注册成功后跳转登录页，登录后即可进入控制台。

登录控制台

注册完成后，访问 登录页面 输入用户名或邮箱与密码。进入控制台后，你通常会用到这些区域：

  • 仪表盘：查看余额、调用概览和系统状态。
  • 令牌管理：创建、复制、禁用或删除 API Key。
  • 日志：查看请求记录、消耗明细和失败原因。
  • 个人设置：修改账号资料、密码和访问令牌。

充值额度

登录控制台后，在钱包或充值页面完成余额充值。充值到账后，额度会用于 API 调用消耗。

提示：实际充值比例、赠送额度、充值卡入口以你的后台配置和页面公告为准。上线前建议把这里改成你的最新规则。

创建令牌

  1. 进入控制台左侧的「令牌管理」。
  2. 点击「添加令牌」，填写令牌名称，例如 Claude Code、Codex CLI。
  3. 选择合适的分组。分组会影响可调用模型、倍率和路由。
  4. 按需设置过期时间和额度上限，不设置则通常长期有效。
  5. 提交后复制 `sk-` 开头的 API Key。令牌只建议保存到本机安全位置。
不要在截图、公开仓库、群聊中暴露 API Key。泄露后请立即删除旧令牌并重新创建。

配置 Claude Code

Claude Code 使用 Anthropic 兼容入口，Base URL 不需要追加 `/v1`。

安装

# macOS / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash

# Windows PowerShell
irm https://claude.ai/install.ps1 | iex

# 或使用 npm
npm install -g @anthropic-ai/claude-code
claude --version

环境变量

export ANTHROPIC_BASE_URL="https://superahhilai.top"
export ANTHROPIC_API_KEY="sk-your-key"

配置 Codex CLI

Codex 使用 OpenAI 兼容入口，Base URL 需要带 `/v1`。

安装

npm install -g @openai/codex
codex --version

环境变量

export OPENAI_BASE_URL="https://superahhilai.top/v1"
export OPENAI_API_KEY="sk-your-key"

Python SDK 示例

from openai import OpenAI

client = OpenAI(
    api_key="sk-your-key",
    base_url="https://superahhilai.top/v1",
    default_headers={"User-Agent": "curl/8.7.1"},
)

response = client.responses.create(
    model="gpt-5.5",
    input="用一句话介绍 SuperAHHilAi。"
)

print(response.output_text)

配置 Gemini CLI

Gemini CLI 使用 Gemini 原生风格入口，配置 API Base URL 和 Key 即可。

npm install -g @google/gemini-cli
gemini --version

export GEMINI_API_BASE_URL="https://superahhilai.top"
export GEMINI_API_KEY="sk-your-key"

CC Switch 配置

CC Switch 可用于管理 Claude Code、Codex CLI、Gemini CLI 等工具的供应商配置。

  1. 打开 CC Switch，选择添加供应商。
  2. 选择自定义或 New API 相关模板。
  3. API 端点填写 `https://superahhilai.top`，API Key 填控制台生成的令牌。
  4. 保存后启用供应商，重新打开终端测试。

如果需要余额显示，请在控制台个人设置中找到访问令牌和用户 ID，并按 CC Switch 的 New API 模板填入。

API 格式

协议 / 工具 Base URL 说明
OpenAI 兼容 https://superahhilai.top/v1 适用于 OpenAI SDK、Codex CLI、Chat Completions / Responses。
Anthropic 兼容 https://superahhilai.top 适用于 Claude Code 和 Anthropic Messages 风格请求。
Gemini 原生 https://superahhilai.top 适用于 Gemini CLI 或 Gemini 风格客户端。

分组说明

分组用于区分不同工具、模型池或计费倍率。创建令牌时，请根据使用场景选择合适分组。

  • Claude / Anthropic 工具请选择 Claude 相关分组。
  • Codex / OpenAI SDK 工具请选择 OpenAI 或 Codex 相关分组。
  • Gemini CLI 请选择 Gemini 相关分组。
  • 如果调用失败，优先检查令牌分组是否允许访问目标模型。

图像接口

如果你的站点开启图像模型，可以通过 OpenAI 兼容入口或控制台中显示的图像接口调用。不同模型支持的尺寸、价格和任务类型可能不同。

建议在模型价格页面确认图像模型名称、倍率和可用状态后再调用。

客户端配置

除了命令行工具，你也可以在 Cherry Studio、Lobe Chat、OpenCat、DeepChat 等客户端里配置自定义 OpenAI 兼容供应商。

  1. 供应商类型选择 OpenAI 兼容或自定义。
  2. Base URL 填 `https://superahhilai.top/v1`。
  3. API Key 填控制台创建的 `sk-` 令牌。
  4. 模型名称按模型价格页或控制台可用模型填写。

并发与限制

接口可能受到账户余额、模型供应商、分组策略、站点限速和上游可用性的共同影响。

  • 余额不足会导致请求失败，请先充值或更换令牌。
  • 高并发任务建议分批提交，并观察日志中的失败原因。
  • 长文本、工具调用、图片任务的消耗可能明显高于普通对话。

常见问题

为什么令牌无法调用模型？

检查余额、令牌状态、分组、模型名称和 Base URL。OpenAI 兼容入口通常需要 `/v1`。

为什么 Claude Code 不能连接？

确认 `ANTHROPIC_BASE_URL` 没有加 `/v1`，并确认 API Key 使用的是控制台创建的 `sk-` 令牌。

为什么充值后余额没更新？

刷新控制台或等待片刻。如果长时间未到账，请联系站长并提供订单信息。
