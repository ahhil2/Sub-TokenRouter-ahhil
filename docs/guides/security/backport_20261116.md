# v0.4.12 漏洞适配审计（2026-11-16）

本次以二开原 v0.4.12（`2cfdd374c565029c9dce6a9ae32d057e9d9d8137`）为基线，检查 TokenFlux/TokenRouter 从 v0.4.0（`c8ee83a521495d5b4e20f5646978e51ad8a9aac1`）到 v0.7.3（`e74bba115fc2cfd77e97a2a22a15dad0605d64d1`）的发布说明、提交及对应实现。范围是已有功能中的安全、计费和数据完整性问题。上游新增功能不在本次移植范围。

“已修复”表示本次修复，“已有”表示原安装包或源码已经覆盖，“不适用”表示二开没有产生该问题的功能或代码路径。业务问题没有公开漏洞编号时，以下使用上游提交定位，不为它们编造 CVE。

身份组余额折扣、AHHilAI 倍率、历史充值快照、退款回收额度、网关容量限制、固定按次价卡及更新器均以二开实现为准。缓存用量修复影响后续请求的实际结算，历史账单不重算。

新增 `309_subscription_refund_hold.sql`，为 `user_subscriptions` 添加可空冻结标记。发布前暂停退款，备份 PostgreSQL 并验证恢复；全部实例和前端切换完成后再恢复退款，旧进程不会执行冻结规则。回退前先处理尚未结束的冻结退款，并保留新增列及退款审计。详见[版本升级说明](../../operations/upgrade_notes.md#subscription_refund_hold)。

本次仍使用 v0.4.12。已安装旧 v0.4.12 的实例需要重新安装替换后的同版本归档；单纯按版本号比较的自动更新检查可能不会提示升级。
